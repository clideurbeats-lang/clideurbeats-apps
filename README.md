# @clideurbeats — plugins & apps

Installeurs macOS (.dmg) de blakdown*, M1DI, K1T, SP4CE, Tempo, Partage et luhpitch.
Téléchargements : voir l’onglet Releases.

## Mises à jour automatiques
- `updates/k1t.json` : dernière version de K1T, lue par le plugin (bouton METTRE À JOUR).
- `updates/installer_k1t_vX.sh` : l'installeur téléchargé par le plugin.
- `downloads/` : installeurs zippés proposés sur le site.
- `updates/luhpitch.json` : dernière version de luhpitch, lue par le plugin (roue des réglages → RECHERCHER).
- `updates/installer_luhpitch_vX.sh` : l'installeur téléchargé puis lancé par luhpitch.
